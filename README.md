# 📸 Instagram Login — DIO

Interface de login inspirada na página inicial do Instagram, desenvolvida como parte dos estudos de **Desenvolvimento Web** na [Digital Innovation One (DIO)](https://www.dio.me/).

O projeto teve como principal objetivo praticar a construção de interfaces utilizando **HTML5, CSS3 e Flexbox**, trabalhando conceitos de estruturação, posicionamento, responsividade e organização visual.

---

## 🚀 Sobre o projeto

Este projeto consiste na recriação da interface de login do Instagram, reproduzindo elementos visuais presentes na página original.

A implementação foi desenvolvida durante os estudos de **Flexbox**, colocando em prática conceitos fundamentais de desenvolvimento front-end.

O projeto também faz parte da minha trajetória de aprendizado em desenvolvimento web e representa uma das etapas da construção do meu portfólio como **Desenvolvedor Full Stack**.

---

## 🛠️ Tecnologias utilizadas

## 📚 Conceitos praticados

Durante o desenvolvimento foram trabalhados conceitos importantes de Front-end, como:

* Estrutura semântica com HTML
* Organização de elementos utilizando CSS

* Alinhamento e distribuição de elementos

## 💻 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Fagner-Lopes-Paiva/instagram-dio-master.git
```

### 2. Acesse a pasta

```bash
cd instagram-dio-master
```

### 3. Execute o projeto

Abra o arquivo:

```text
index.html
```

Você também pode utilizar uma extensão como **Live Server** no VS Code para executar o projeto localmente.
